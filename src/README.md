# A Website for Managing my Wedding 
  
This is a personal website created to help manage and organize the details of my wedding. It includes features such as guest list management, RSVP tracking, event scheduling, and vendor coordination.

## Features
- Guest List Management: Add, edit, and remove guests from the wedding guest list.
- RSVP Tracking: Monitor who has responded to the invitations and their meal preferences.
- Event Scheduling: Create and manage the schedule for wedding events (ceremony, reception, dinner, etc.).


## Technologies Used

- Frontend:  HTML5, CSS (Bootstrap)
- Backend:  Django + SQLite
